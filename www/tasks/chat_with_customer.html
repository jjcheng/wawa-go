Meta does allow initiating a new conversation with any phone number without a template message, but you can still interact with your customers if the last user's reply was within 24 hours. Go to Chats page, select a customer, chat with him/her just like using the app. Any incoming messages are automatcally pushed to the chat room, any status updated is represented by ticks just like on WhatsApp.

If a new message arrived while the CRM user is outside of the chat room. He or she can still receive the notification.
